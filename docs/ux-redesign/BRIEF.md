# Design brief — MEnglish UI redesign (step 1: images only)

Author: Claude (dev agent). Implementation of the static mockups: Codex. Skill used: `ui-ux-pro-max`.
Scope: 6 static, **responsive single-file HTML mockups** in `docs/ux-redesign/screens/` (one file renders both 1440 and 390 via Tailwind breakpoints). No app code, no Vue, no JS frameworks. Tiny vanilla JS only for the mobile drawer / tab toggles is allowed.

## Hard rules
- Tailwind classes only, from the app's real tokens (`tailwind.config.js` is reused by `docs/ux-redesign/build.sh`). CTA `bg-primary-container` (#c2410c) with white text; `text-primary` (#a23f00) for orange text/links; `bg-brand` (#f5691a) decorative only (never text bg); sidebar `bg-sidebar` (#111a2b); page `bg-background` (#f9f9ff); warm tint `bg-primary-light`/#fff7ed; success = `tertiary`, danger = `error`, warning = `warning`, info = `info`. Font Be Vietnam Pro (already in the CSS). Icons: Material Symbols Outlined via `<span class="material-symbols-outlined">name</span>`.
- Vietnamese UI strings (same wording as the current app where it exists). Keep the information architecture, tabs, permissions semantics and every current action/field. Improve layout, hierarchy, density, mobile behaviour only.
- All numbers/names are **SAMPLE DATA**: every file shows a small fixed badge "Dữ liệu mẫu — bản thiết kế" (top right of the content area, `text-xs`, neutral). Names use the `# ` demo prefix style, phones `039…`.
- A11y: contrast ≥ 4.5:1, text ≥ 12px (body 14px, mobile inputs 16px), touch targets ≥ 44px on mobile, visible `focus-visible` ring (`ring-2 ring-primary-container`), icon-only buttons have `aria-label`, one `<h1>`, landmarks (`<nav>`, `<main>`), status never by colour alone (icon + text).
- Shell: desktop (≥1200px) = navy sidebar 240px (logo "MENGLISH / HỆ THỐNG QUẢN TRỊ", grouped nav with the active item `bg-primary-container`) + sticky topbar (page title, search, bell badge, user chip). Mobile (<768px) = sticky topbar with hamburger, title, search + bell icons; the screen content is full-width, no sidebar rendered (drawer closed). Teacher screen additionally has a fixed bottom tab bar.
- Each file `<link rel="stylesheet" href="../assets/mockup.css">`, `<html lang="vi">`, viewport meta. Max content width on desktop fills the area (no 430px phone frame).
- Do not add external requests (no CDN, no images from the net). Avatars = initials circles.

## Screens (route → what is wrong today → target design)

### 01 `dashboard.html` — Tổng quan (Admin) `/dashboard`
Today: 4 equal KPI cards, then a long "Cần bạn xử lý" list where 5 near-identical "Chăm sóc tháng đầu" rows drown the rest; operational alerts are a second list with unlabeled red numbers; branch comparison and weekly revenue are below the fold; mobile page is 3,500px tall with every block at equal weight.
Target: greeting + date; KPI strip (Doanh thu tháng 10/2026, Học viên đang học, Lead mới, Lớp đang chạy) with delta chips; **"Cần xử lý" grouped by type** (Học phí, Chăm sóc, Duyệt) as a tabbed/segmented list with counts and ONE primary action per row, "Xem tất cả" per group; "Cảnh báo vận hành" as 4 compact severity tiles (icon + number + label); revenue-by-week mini bar chart and branch comparison table (desktop 2-col). Mobile: KPI as 2×2 grid, alert tiles as horizontal scroll chips, task groups as accordion, branch table → stacked cards.

### 02 `teacher-today.html` — Lịch dạy hôm nay (Giáo viên) `/teacher/home`
Today: per-session 5 equal step cards (Check-in, Điểm danh, Bài giảng, Giao bài tập, Nộp báo cáo) with locked ones as dashed grey boxes; floating "ORDER" button overlaps content/bottom bar on mobile; 1,400px desktop, 3,700px mobile.
Target: session card with time rail (17:30 / đến 19:00 / Ca chiều), class title, room·branch·HV count, and a **single horizontal stepper** (Check-in ✓ → Điểm danh → Bài giảng → Giao bài tập → Nộp báo cáo) where only the CURRENT step is expanded with one primary CTA; later steps are collapsed chips with lock icon; secondary links (Mở giáo trình, Nhập điểm, Trang lớp) as a text-button row. Ended session collapses to one line. "Buổi đã dạy chưa điểm danh · 7" as a compact warning list with Còn 4 giờ / Quá 24h badges. "Học sinh cần chú ý" side card (desktop) / below (mobile). Weekly strip as a 7-day scroller. Mobile: bottom tab bar (Lịch dạy, Bảng công, Thông báo, Cá nhân), ORDER becomes an item in a "+" action sheet button above the tab bar that never covers content (add bottom padding).

### 03 `receipt-create.html` — Lập phiếu thu học phí `/tuition/receipts/create`
Today: 2,700px single column of 6 cards; sticky action bar floats over the form; the money summary is in the middle; selects truncate student/class text.
Target: **2-column on desktop**: left = 4 numbered steps (1 Học viên & khoản thu, 2 Học liệu/phí/phụ thu, 3 Hình thức thu tiền, 4 Minh chứng), right = **sticky summary panel** (breakdown: học phí 13 buổi × 395.833 đ, học liệu, phí thi, khoản khác, giảm trừ, phụ thu, **Tổng thực thu** large; validation "Hợp lệ để gửi duyệt") with the buttons Hủy bỏ / Lưu nháp / **Lưu phiếu thu & Gửi duyệt** at its bottom. Student card = compact header (avatar, name, mã HV, lớp, trạng thái) + 4 stat cells (đã đóng/đã trừ/tồn/trạng thái). Payment method as segmented control (Chuyển khoản / Tiền mặt) with the status notices inside. Mobile: single column, summary becomes a bottom sheet bar showing the total + primary CTA (collapsible breakdown), steps as accordion with a progress indicator "Bước 1/4".

### 04 `crm-customers.html` — Danh sách khách hàng (CRM) `/crm/customers`
Today: tabs + title + 7 stage chips + 5 filters + bulk bar + 8-column table where Nguồn truncates ("Facebook A…"), SLA is multi-line and the row action is only a pencil; on mobile the list is cards but filters take a whole screen.
Target: page header (title + "Nhập Excel" secondary + "Thêm khách mới" primary); **stage chips as a single scroller with counts** (Tất cả, Chưa liên hệ >24h danger, Hẹn test hôm nay, Cần gọi lại, Chờ xếp lớp, Đã nhập học, Thất bại); one search field + a "Bộ lọc (n)" button opening a popover (desktop inline row collapses to search + 2 key filters: Nguồn, Người phụ trách) ; table with sticky header, columns Khách (name + mã + phone with tel link) · Phụ huynh · Giai đoạn · Liên hệ tiếp theo / SLA (icon+text, one line) · Phụ trách (avatar) · Nguồn (no truncation, tooltip) · row actions (Gọi, Xem, ⋯ menu) ; bulk bar appears only when rows are selected. Mobile: cards with name, stage badge, SLA chip, tap-to-call button, filters in a bottom sheet trigger.

### 05 `timesheet-teachers.html` — Chi tiết chấm công giáo viên `/payroll/timesheets/teachers`
Today: 7 tabs, filter row of 6 truncated controls, "Chấm công theo lịch" block, 3 summary tiles, then a 65-row table with 3-line cells (ca học, lớp, trạng thái) — 3,000px desktop / 5,500px mobile.
Target: header (title, kỳ lương chip "Tháng 10/2026 · Đang tính", actions Lịch sử đồng bộ / Chấm công thủ công); **summary tiles first** (Chờ đối soát, Hợp lệ (tính lương), Từ chối) clickable as filters; compact filter bar (search + kỳ + 3 selects + Lọc) with active-filter chips; "Chấm công theo lịch" as a collapsible banner card with inline Xác nhận; main table **grouped by date** with single-line rows: Ca (icon+time) · Lớp · Giáo viên (avatar) · Vào/Ra (vs lịch, delta chip) · Số giờ · Tình trạng (Đầy đủ / Thiếu vào) · Trạng thái duyệt · edit icon; sticky header and sticky bulk bar "Chốt bảng công" . Mobile: date-grouped cards (time + class, GV, vào/ra, badges), summary tiles as a 3-up scroller.

### 06 `approvals.html` — Việc cần duyệt `/approvals`
Today: 5 role-type tabs, filter pills with counts, then stacked grouped lists where each row is a title + grey meta + chevron; amounts, requester and age are hard to scan; no bulk path for the 6 phiếu thu.
Target: header with total pending (21) and an urgency line ("3 quá hạn"); pill tabs with counts (Tất cả 21, Phiếu thu 6, Đào tạo 9, Hành chính, Nhân sự…); **master–detail on desktop**: left list (checkbox, type icon, title, requester avatar+name, amount right-aligned in mono, age badge "2 ngày"), right preview pane of the selected item with key facts and **Duyệt / Từ chối** buttons (+ reason field for reject) ; bulk bar "Duyệt n mục" when ticked. Group headings sticky with "Xem tất cả". Mobile: list only; tap opens a full-screen detail sheet with Duyệt/Từ chối pinned at the bottom.
